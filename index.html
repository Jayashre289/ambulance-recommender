How the score is built

Every hospital is re-scored the moment a call comes in, using live-modeled conditions rather than a static map. Four factors are normalized to 0–100 and combined by weight:

score = (ICU% · wicu + specialist_match · wspec + (100 − ER_load%) · wload + eta_score · weta) / Σw
Factor 01

ICU availability

Open ICU beds as a share of each hospital's ICU capacity — the strongest predictor of whether a critical patient gets treated on arrival or waits.

Factor 02

Specialist match

Whether the on-duty team covers the case type — cardiac, trauma, neuro, burns, pediatric. A close hospital without the right specialist scores low here on purpose.

Factor 03

ER load

Current emergency-room utilization. A hospital running near full load absorbs a new critical patient far worse than a quieter one a few minutes further out.

Factor 04

Travel time

Estimated transit time from live position, scaled against the other candidates in this scenario. It still matters — it's just no longer the only thing that matters.

Behavior

Dynamic rerouting

Conditions can change mid-transit — a bed fills, a load spikes. When that happens en route, the system re-scores and can redirect the ambulance before arrival.

In production

Real data sources

This demo randomizes hospital telemetry. A live deployment would pull ICU/bed counts from hospital bed-management systems, ER load from triage systems, and position from ambulance GPS/telematics.

Data sources

Dataset 01

Urban Traffic Flow Dataset

Kaggle (ziya07). 200 sensor readings of vehicle speed and congestion level across peak/off-peak windows. Used to calibrate the speed and congestion values sampled for every ETA calculation — replacing a flat guess with distributions drawn from the data (mean ~61.6 km/h, congestion-level frequencies per traffic period).

Dataset 02

Hospital Patient Records Dataset

Kaggle (blueblushed). ~984 patient records across 15 conditions. Used for the emergency case types simulated (Heart Attack, Stroke, Childbirth, Kidney Stones, etc.) and for the average length of stay, discharge status, and readmission rate shown as an outcome projection once the ambulance arrives.

Not from these datasets

Hospital ICU / bed / load figures

Neither dataset contains real-time hospital capacity data, so ICU availability and ER load are still randomly simulated each run — they are not live figures from these six hospitals.

Hospitals modeled in this simulation

Names and locations are real Chennai hospitals. Bed counts are approximate published figures used for scale; ICU availability and ER load shown in the simulation are randomly generated each run and are not real, live data from these hospitals.

Golden Minute is a simulation built for an academic proposal on treatment-readiness-first ambulance routing. It models a virtual dispatch scenario over real Chennai hospital locations; it is not connected to any hospital's real systems and does not reflect real capacity.
